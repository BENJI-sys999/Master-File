.# StudentComm — Local Student Communication Prototype

Quick local prototype for a student communication site. It's a static frontend that stores data in the browser `localStorage`.

Features
- Create chat rooms
- Send messages (stored per-room)
- Post announcements
- Set display name

How to run
1. Open `student_comm/index.html` in your browser.
2. Set your name in the top-right, create or pick a room, and start messaging.

Next steps

- Add user authentication and persistence on a server.
